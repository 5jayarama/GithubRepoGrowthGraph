New GitHub Repositories Created Per Month

This graph is updated daily. The data is fetched from the GitHub Search API. It covers ONLY public repos - private repos are NOT counted because they are invisible to this API. The current month is excluded because it is still in progress.

Monthly count Smoothed curve ChatGPT release (Nov 30, 2022)

The API gives the program the y number of repos created during x month by scraping all CURRENTLY AVAILABLE public repos. This means that if a repo is DELETED, it will no longer be counted by the API, and thus decrease the y repo counter for x month. Basically, what this means is that if the graph shows March 2019 with 1.3 million repos today, it can show 1.2 million repos next week - if 100,000 public repos made in March 2019 are deleted or made private during that time frame.
